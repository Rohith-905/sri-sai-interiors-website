# Sri Sai Interiors — basic website

A premium, responsive static website made with HTML, CSS, and vanilla JavaScript. Designed for GitHub Pages.

## Files
- index.html — website content and sections
- style.css — design and mobile-responsive layout
- script.js — mobile navigation and enquiry-to-WhatsApp behavior

## Before publishing
1. Open script.js.
2. Set BUSINESS_WHATSAPP to your real WhatsApp number in international format, digits only. For India, start with 91. Do not include +, spaces, or hyphens.
3. Set BUSINESS_PHONE to your business phone number in the same format.
4. Replace sample image URLs with your own project photos when available. The current photos are illustrative samples, not verified Sri Sai Interiors projects.
5. Open index.html in a browser and test the page. The enquiry form opens WhatsApp with a prefilled message; the customer must press Send in WhatsApp.

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select the default branch and folder /(root), then Save.
4. Wait for the Pages deployment to complete. The URL should look like https://YOUR-USERNAME.github.io/sri-sai-interiors-website/
5. Test the published website on desktop and mobile.

## Notes
- This is a static website; it has no backend, database, admin panel, or server-side enquiry storage.
- The enquiry form does not silently send or store customer information.
- Sample photos are loaded from Unsplash and require an internet connection.
- GitHub Pages hosting is free for eligible public repositories.
